# WM Zeiten

Eine kleine Web-App fuer die FIFA World Cup 2026 Spielorte:

- Live-Ortszeit aller 16 Spielorte
- Leaflet-Karte mit Stadion-Markern
- Liste der heutigen und kommenden Spiele
- Direkte Karten-Navigation aus der Spieleliste

## Starten

Die App laeuft direkt als statische Seite:

```text
index.html
```

Optional kann sie mit Node.js gestartet werden:

```bash
npm run dev
```

Die Kartenkacheln und Leaflet werden aus oeffentlichen CDNs geladen.
